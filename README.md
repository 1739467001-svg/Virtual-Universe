# 🌌 VR 太阳系漫游 · Solar System

一个基于 **Three.js + WebXR** 的太阳系模拟与漫游项目。
桌面端用鼠标即可自由漫游；接上 VR 头显（或手机 Cardboard）后，点 **Enter VR** 即可进入沉浸式宇宙。

无需构建、无需安装依赖、**完全离线可用**（Three.js 已打包进 `vendor/`）。

---

## ✨ 功能

- **太阳 + 八大行星**：按"可观赏比例"缩放，保留相对大小与轨道顺序；太阳带颗粒纹理与光晕。
- **真实行星贴图**：八大行星 + 太阳 + 月球均采用真实位图贴图（已随仓库打包，离线可用）；地球叠加**法线贴图**（地形起伏）、**高光贴图**（海洋反光）、**夜晚灯光自发光**（夜半球城市灯火）与独立飘动的云层。加载失败时自动回退到 Canvas 程序化纹理。
- **Bloom 辉光后期**：太阳与日冕经 UnrealBloom + ACES 色调映射处理，明亮通透、富有电影感。
- **银河天空盒**：真实 Milky Way 立方体贴图包裹整个场景，叠加近景星点增强纵深。
- **太阳日冕/耀斑动画**：太阳外层光晕持续脉动、缓慢旋转，恒星「活」了起来。
- **真实自转轴倾角**：地球 23.4°、天王星 97.8°（横躺打滚）、金星 177°（近乎倒转）等均按真实值。
- **公转 + 自转**：各天体按相对真实周期运行（含金星/天王星的逆向自转），可见轨道线。
- **卫星与行星环**：地球带月球；土星环含卡西尼缝，土星/天王星环随自转轴一起倾斜。
- **小行星带**：火星与木星之间 1500 颗小行星缓慢公转。
- **星空背景**：6000 颗星包裹整个场景。
- **自由漫游**：鼠标拖拽旋转、滚轮缩放、右键平移。
- **🚀 自由飞行（飞船视角）**：一键进入第一人称漫游，`WASD/QE` 平移、鼠标转向、`Shift` 加速、滚轮调速，真正驾驶相机近距离飞掠每一颗行星。
- **🛰 沉浸飞行增强**：点行星名**平滑飞掠**过去并在合适距离悬停；右下角**仪表盘**实时显示速度/坐标/最近天体距离；右下角**小地图雷达**俯瞰你在太阳系中的位置与朝向；靠近行星**自动减速并防穿模**，可贴着表面环绕观测。
- **点击聚焦**：点行星或左下角名称按钮，相机平滑跟随并弹出科普信息卡。
- **时间控制**：暂停/继续、0–500× 调速。
- **WebXR**：右下角 `Enter VR` 进入沉浸模式（需支持 WebXR 的浏览器 + 头显）。

## 🚀 运行方法

因为用到了 ES Module 和 importmap，**不能直接双击打开 `index.html`**（`file://` 会被浏览器的跨域策略拦住），需要用一个本地静态服务器。任选一种：

```bash
# 方式一：Python（几乎人人都有）
python3 -m http.server 8000

# 方式二：Node
npx serve .
```

然后浏览器打开 <http://localhost:8000> 即可。

> 推荐用 Chrome / Edge / Firefox 等现代浏览器。进入 VR 需要支持 WebXR 的浏览器与设备。

### 🚀 自由飞行（飞船漫游）

点击 **🚀 自由飞行**（或随时按 ESC 退出），即可亲自驾驶相机在太阳系中飞行，近距离观测每一颗行星：

| 按键 | 说明 |
| --- | --- |
| 点击行星名按钮 | 平滑飞掠过去并在合适距离悬停 |
| 移动鼠标 | 转向（指针锁定，像第一人称视角一样自由环顾） |
| `W` / `S` | 前进 / 后退 |
| `A` / `D` | 左移 / 右移 |
| `Q` / `E` | 下降 / 上升 |
| `Shift` | 加速（飞向远处行星时按住） |
| 滚轮 | 调整飞行速度 |
| `ESC` | 退出自由飞行，回到轨道视角 |

## 🛠 技术说明

- **比例不是真实比例**：真实尺度下行星相对太阳与轨道太小，肉眼几乎不可见。本项目对半径与轨道距离做了非线性压缩，**保留顺序与相对大小关系**，优先保证可观赏性。
- **光照**：太阳处放置点光源，并刻意关闭了距离衰减（`decay=0`），让最远的海王星也能被照亮。
- **行星外观**：默认加载 `assets/textures/` 下的真实位图贴图（含地球法线/高光/夜灯多层）；土星环仍用程序化生成（含卡西尼缝 + 透明带）。任一贴图加载失败会自动回退到 Canvas 程序化纹理，保证离线/弱网环境照常显示。
- **后期与色彩**：`ACESFilmicToneMapping` + `UnrealBloomPass`，仅对太阳/日冕等高亮区域产生辉光（`threshold≈0.85`），行星表面保持清晰不泛白。
- **自转轴倾角**：通过「公转 pivot → 竖直 holder → 倾斜 tiltGroup → 自转 mesh」的层级实现，行星环与卫星挂在 tiltGroup 上，随赤道面一起倾斜。
